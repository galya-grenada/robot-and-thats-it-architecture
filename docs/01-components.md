# 01. Описание компонентов

## Люди

| Роль | Описание | Как взаимодействует |
|---|---|---|
| Посетитель | Гость, оформляет заказ на сайте, в приложении или терминале | Web, Mobile, Terminal (заказ); Order Tableau (готовность); получает уведомления |
| Менеджер по гостеприимству | Отменяет заказы по обращениям гостей, получает уведомления о сбоях | Service Web (отмена заказа); получает уведомления о сбоях |
| Менеджер по ассортименту | Настраивает меню, акции и скидки | Service Web |
| Технолог | Ведёт технологические карты блюд | Service Web |
| Администратор | Управляет учётными записями сотрудников и правами доступа | Service Web |

## Внешние системы

| Система | Описание | Взаимодействует с | Для чего |
|---|---|---|---|
| Платёжный сервис | Принимает оплату заказов и выполняет возвраты | Payment Service | Запрос оплаты/возврата, получение результата |
| Роботы | Готовят заказы по заданию, сообщают остатки ингредиентов | Robots Service | Передача заказа на приготовление, получение остатков |
| Склад | Принимает заказы на пополнение продукции | Supply Service | Заказ продукции |
| Система лояльности | Ведёт бонусные счета посетителей, начисляет и списывает бонусы | Clients Service | Обмен данными посетителя и бонусами |

## Клиентские приложения

| Контейнер | Технология | Назначение | Взаимодействует с |
|---|---|---|---|
| Web | React / Angular, TypeScript | Веб-версия приложения для оформления заказа посетителем через браузер | API Gateway (REST) |
| Mobile | React Native (iOS/Android) | Мобильное приложение для оформления заказа со смартфона | API Gateway (REST) |
| Terminal | Electron / kiosk-приложение, JavaScript | Киоск самообслуживания в зале ресторана | API Gateway (REST) |
| Order Tableau | JavaScript, WebSocket-клиент | Табло в зале, показывает статус готовности заказа | API Gateway (WSS) |
| Service Web | React / JS | АРМ сотрудника: меню, техкарты, отмена заказов, права доступа, заказы поставок | API Gateway (REST) |

## Платформенные контейнеры

| Контейнер | Технология | Назначение | Взаимодействует с |
|---|---|---|---|
| API Gateway | Spring Cloud Gateway | Единая точка входа: маршрутизация запросов и проверка токена. Бизнес-логики не содержит | Клиентские приложения; IAM, Menu, Orders, Clients, Supply (REST); Tableau Service (WSS) |
| Message Broker | Apache Kafka | Событийная шина между сервисами | Все сервисы, публикующие или читающие события |

## Микросервисы

| Сервис | Технология | Назначение | Взаимодействует с (и для чего) | Своя БД |
|---|---|---|---|---|
| IAM Service | SpringBoot, Spring Security | Аутентификация и авторизация посетителей и персонала, роли и права | Gateway: вход; Notification: контакты сотрудников (REST); Kafka: публикует `UserRegistered` | IAM DB |
| Menu Service | SpringBoot | Хранение и выдача актуального меню, техкарт, правил скидок и акций | Gateway: выдача и правка меню; Kafka: публикует `MenuUpdated` | Menu DB |
| Orders Service | SpringBoot | Создание, обработка и отмена заказов, хранение статуса | Gateway: создать, отменить, статус; Payment: оплата заказа (`Pay Order`, REST, результат в ответе); Robots: отдаёт состав заказа (`Get Order`); Kafka: публикует `OrderCancelled`, читает `OrderReady`, `MenuUpdated` | Orders DB |
| Clients Service | SpringBoot | Профили посетителей, контакты, обмен данными и бонусами с системой лояльности | Gateway: профиль; Notification: контакты (REST); Kafka: читает `UserRegistered`, `OrderPaid`; Система лояльности | Clients DB |
| Payment Service | SpringBoot | Обработка оплаты и возвратов через платёжный сервис | Orders: принимает `Pay Order` и сразу возвращает результат; Kafka: читает `OrderCancelled` (возврат), публикует `OrderPaid`; Платёжный сервис | Payment DB |
| Robots Service | SpringBoot | Передача заказа роботам, приём остатков и статусов | Kafka: читает `OrderPaid`, публикует `OrderReady`, `StockUpdated`, `RobotFailed`; Orders: запрашивает состав заказа; Роботы | нет (адаптер) |
| Supply Service | SpringBoot | Формирование и отправка заказа продукции на склад при нехватке запасов | Gateway: ручной заказ; Kafka: читает `StockUpdated`; Склад | Supply DB |
| Tableau Service | Node.js / WSS | Управление табло выдачи: рассылает статус готовности | Kafka: читает `OrderReady`; Gateway: соединение с табло | нет |
| Notification Service | Go | Формирование и отправка Push/SMS/E-mail посетителям и сотрудникам по событиям | Kafka: читает `OrderReady`, `OrderCancelled`, `UserRegistered`, `RobotFailed`; Clients, IAM: контакты (REST) | нет |

## Базы данных

Каждая БД принадлежит одному сервису, другие сервисы читают её данные только через его API или события.

| БД | СУБД | Сервис | Что хранит |
|---|---|---|---|
| IAM DB | PostgreSQL | IAM Service | Учётные записи, роли, права, контакты сотрудников |
| Menu DB | PostgreSQL | Menu Service | Позиции, техкарты, акции и скидки |
| Orders DB | PostgreSQL | Orders Service | Заказы, состав, статусы, копия цен из меню |
| Clients DB | PostgreSQL | Clients Service | Профили и контакты посетителей |
| Payment DB | PostgreSQL | Payment Service | Платёжные транзакции |
| Supply DB | PostgreSQL | Supply Service | Остатки, пороги, заказы на склад |
